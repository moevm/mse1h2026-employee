## 5. Руководство пользователя с ролью *Стажер*
Пользователь с ролью *Стажер* имеет теже команды, что и пользователь с ролью *Сотрудник*, но ряд действий ему недоступен.

## 6. Общие команды для различных ролей
Для всех ролей реализованы следующие команды:
* Команда *Главное меню* возвращает из подменю к основному меню команд этой роли;
* Команда *Выйти* возвращает из меню роли в меню пользователя без роли. При этом роль также будет выставлена без роли.
