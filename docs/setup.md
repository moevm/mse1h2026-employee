# Руководство по настройке и развертыванию приложения

Данный документ описывает процедуру первичной настройки среды выполнения, получения ключей доступа для Telegram-бота и интеграции с сервисами Google.

## 1. Подготовка конфигурационного файла

1. Скопируйте файл `.env.example`, находящийся в корневой директории проекта, и сохраните его под именем `.env`.
2. Откройте файл `.env` в любом текстовом редакторе.
3. Заполните пустые значения переменных в соответствии с инструкциями ниже.

## 2. Получение токена Telegram-бота (BOT_TOKEN)

Для взаимодействия системы с платформой Telegram необходимо зарегистрировать нового бота и получить уникальный ключ доступа (токен).

1. Откройте приложение Telegram и найдите системного бота **@BotFather**.
2. Отправьте команду `/newbot` для создания нового бота.
3. Введите отображаемое имя бота (например, `Corporate Task Manager`).
4. Введите уникальное имя пользователя бота (username), которое должно обязательно оканчиваться на `bot` (например, `company_employee_bot`).
5. В ответном сообщении @BotFather предоставит токен вида `1234567890:ABCDEFGHIGKLMNOPQRSTUVWXYZ`.
6. Скопируйте полученный токен и вставьте его в файл `.env` в качестве значения переменной `BOT_TOKEN`.

## 3. Настройка интеграции с Google Sheets

Система использует API Google Sheets в качестве базы данных. Для авторизации запросов применяется сервисный аккаунт Google (Service Account).

### 3.1. Создание сервисного аккаунта и получение ключа

1. Перейдите в консоль разработчика Google Cloud Console (https://console.cloud.google.com/).
2. Создайте новый проект или выберите существующий.
3. Перейдите в раздел **"APIs & Services" (API и сервисы)** -> **"Library" (Библиотека)**.
4. Найдите и активируйте следующие API:
   * **Google Sheets API**
   * **Google Drive API**
5. Перейдите в раздел **"APIs & Services"** -> **"Credentials" (Учетные данные)**.
6. Нажмите **"Create Credentials" (Создать учетные данные)** и выберите **"Service Account" (Сервисный аккаунт)**.
7. Укажите имя сервисного аккаунта и нажмите "Create and Continue", затем "Done".
8. В списке сервисных аккаунтов нажмите на созданный аккаунт. 
9. Перейдите на вкладку **"Keys" (Ключи)**.
10. Нажмите **"Add Key"** -> **"Create new key"**, выберите формат **JSON** и нажмите "Create".
11. Файл с ключом будет автоматически загружен на устройство. Переименуйте его в `credentials.json` и поместите в корневую директорию проекта. Убедитесь, что значение переменной `GOOGLE_CREDENTIALS_PATH` в файле `.env` совпадает с названием этого файла.

### 3.2. Предоставление доступа к Google Таблице

1. Создайте новую таблицу в Google Sheets, которая будет использоваться в качестве базы данных.
2. Вернитесь в Google Cloud Console и скопируйте email-адрес созданного сервисного аккаунта (он имеет формат `имя@проект.iam.gserviceaccount.com`).
3. Откройте созданную Google Таблицу. Нажмите кнопку **"Настройки доступа" (Share)** в правом верхнем углу.
4. Вставьте скопированный email-адрес сервисного аккаунта в поле добавления пользователей.
5. Установите уровень доступа **"Редактор" (Editor)** и снимите галочку "Уведомить пользователей" (Notify people). Нажмите "Открыть доступ" (Share).
6. Запустите скрипт инициализации таблиц:
```bash
python3 setup/init_tables.py
```

### 3.3. Получение идентификатора таблицы (GOOGLE_SHEET_ID)

1. Откройте рабочую таблицу в Google Sheets.
2. Обратите внимание на URL-адрес страницы в адресной строке браузера. Он имеет следующий формат:
   `https://docs.google.com/spreadsheets/d/1A2B3C4D5E6F7G8H9I0J/edit#gid=0`
3. Скопируйте строку символов, находящуюся между `/d/` и `/edit`. В приведенном примере это `1A2B3C4D5E6F7G8H9I0J`.
4. Вставьте скопированный идентификатор в файл `.env` в качестве значения переменной `GOOGLE_SHEET_ID`.

После завершения описанных действий система полностью готова к запуску.
