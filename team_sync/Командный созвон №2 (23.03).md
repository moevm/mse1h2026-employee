## Протокол встречи
* Задача: Реализация команды предложения задачи сотрудником \
Создание сервиса предложения задачи. Вводятся название задачи и её тело. После этого осуществляется выбор руководителя из числа привязанных к сотруднику, создающему задачу. Затем задача отправляется на подтверждение выбранному руководителю.

* Задача: Реализация команды выдачи роли \
Вместо ручного ввода данных в тестовую бд реализован функционал добавления роли пользователю из бота. Суперпользователь может просматривать список запросов ролей и на его основе одобрять или отказывать в выдаче роли.

* Задача: Реализация команды запроса роли \
Пользователь получает возможность запросить одну из доступных ролей. После выбора роли его id и желаемая роль сохраняются в таблицу для дальнейшего рассмотрения суперпользователем.

*  Задача: Реализация команд фиксации рабочего времени \
Реализован функционал кнопок Начать рабочий день и Завершить рабочий день. При нажатии на кнопку Начать рабочий день осуществляется запись id пользователя и времени начала работы в таблицу. При нажатии на кнопку Завершить рабочий день запись обновляется и добавляется время завершения работы пользователем.

* Задача: Экранирование меню различных ролей \
Реализован функционал защиты меню пользователей различных ролей. Теперь для доступа к нему необходимо выполнить логаут из роли и авторизоваться под той, к меню которой требуется обратиться.
