## Протокол встречи
* Задача: Скрывать роли которые уже есть у пользователя при запросе ролей \
Реализован функционал сокрытия ролей, имеющихся у пользователя. Исправлен функционал предложения задачи сотрудником, теперь запросы автоматически отправляются всем руководителям, привязанным к нему.

* Задача: Настройка уведомлений для пользователя. \
Реализован функционал включения и отключения уведомлений, настройка их времени отправки и часового пояса из заранее определенного списка.

* Задача: Отзыв роли \
Реализован функционал отзыва конкретной роли у пользователя с сохранением остальных ролей.

*  Задача: Создание шаблона env и инструкции получения тг-токена \
Создан шаблон env для дальнейшего дозаполнения и инструкция для получения тг-токена и подключения Google таблиц

* Задача: Команда привязки руководителей \
Реализован функционал добавления куратора. Сотрудник отправляет запрос, руководитель его подтверждает.
