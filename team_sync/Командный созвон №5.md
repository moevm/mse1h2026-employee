## Протокол встречи
* Задача: Ежедневный отчет сотрудника \
Реализован функционал создания сотрудником ежедневного отчета о его деятельности и просмотра руководителем созданных отчетов.

* Задача: Скрипт для автоматизированной генерации таблиц при запуске проекта \
Реализован скрипт для автоматического создания таблиц. Повторные запуски скрипта не создают дубликаты уже имеющихся таблиц. Проведена оптимизация записи заголовков для уменьшения числа обращений к Google таблицам при создании.

* Задача: Просмотр комментария к непринятому отчету \
Реализован функционал для просмотра причины отказа от принятия отчета по задаче для сотрудников и стажеров.

*  Задача: Блокировка пользователя \
Реализован функционал блокировки пользователя. После блокировки бот перестает быть ему доступным и при попытке вызвать команду /start будет выведено соответствующее сообщение. Также возможна разблокировка пользователя.

* Задача: Автоматизированная отчистка старых данных \
Реализован функционал автоматического удаления устаревших данных. Для таблиц запросов (задач, ролей и руководителей) отчистка происходит спустя месяц с момента запроса, для отчетов, посещений и принятых задач спустя год. Отчистка стандартно выполняется в 15:00 по мск.
