## Протокол встречи
* Задача: Создание подсистемы напоминаний \
Реализовано константное время напоминаний. Добавлен сервис напоминаний, использующий планировщик задач по временному тригеру из настроек. В main добавлена инициализация сервиса. 

* Задача: Объединение и реструктуризация проекта \
На основе реквестов остальных участников команды преобразована структура проекта к классической архитектуре Python-бота. 

* Задача: Реализация меню руководителя и перехода между меню \
Создан макет меню руководителя. Реализован единый механизм перехода между окнами меню различных ролей бота. 

* Задача: Создание подсистемы авторизации \
При нажатии на клавишу авторизации пользователю отображается список доступных ему ролей на основании данных из таблицы. При выборе соответствующей роли осуществляеться переход к её меню. 

* Задача: Завершение реализации меню \
Реализованы оставшиеся меню проекта и перенесены меню из прототипов 1-й итерации. Созданы заглушки для нереализованных функций бота.
